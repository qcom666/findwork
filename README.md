# FindWork

Лиды для фрилансеров: заведения России, которым нужен сайт, с оценкой потребности, проверкой сайта и готовым питчем.
Данные только открытые (Overture Maps, OpenStreetMap), без платных лицензий. Подробнее: [docs/DATA-SOURCES.md](docs/DATA-SOURCES.md).

## Запуск

Нужны Node 22+ и Python 3.9+.

```bash
# 1. база лидов
python3 -m venv ingest/.venv
ingest/.venv/bin/pip install -r ingest/requirements.txt
ingest/.venv/bin/python ingest/overture.py        # ~2 мин, выгрузка России из Overture
ingest/.venv/bin/python ingest/osm.py             # необязательно, долго: 15 городов через Overpass
ingest/.venv/bin/python ingest/build_db.py        # склейка, скоринг, data/leads.db

# 2. приложение
npm install
cp .env.example .env.local                        # добавьте ANTHROPIC_API_KEY для питчей от Claude
npm run dev                                       # http://localhost:3000
npm test                                          # кредиты, платежи, фильтры, маски контактов, метрики (CI гоняет их на каждый пуш)
```

Без `ANTHROPIC_API_KEY` питч собирается из шаблона. Без ключей ЮKassa локально работает тестовая оплата кнопкой (в продакшене её нет).

Деньги и аккаунты: регистрация даёт 3 кредита, 1 кредит открывает контакты лида вместе с проверкой сайта и питчем, пакеты кредитов
и подписки (1, 3 или 12 месяцев, без автопродления) покупаются через ЮKassa. Цены пакетов меняются в `src/lib/billing.ts`, тарифы и скидки за срок в `src/lib/plans.ts`. Деплой на Vercel: [docs/DEPLOY.md](docs/DEPLOY.md). Модель задаётся в `ANTHROPIC_MODEL` (по умолчанию `claude-opus-5-5`,
для экономии подойдёт `claude-haiku-5-5`).

## Что есть на сайте

* Светлая и тёмная тема с переключателем в шапке (первый визит следует системной, выбор запоминается).
* Каталог с фильтрами: что вы делаете (сайты, QR-меню, онлайн-запись, соцсети, лого, SEO, магазины), ниша, город,
  статус сайта, минимальная оценка, контакты, сортировка. Фильтры применяются сразу, ссылка на выдачу делится.
* Сброс пароля по почте (Resend, включается `RESEND_API_KEY` и `EMAIL_FROM`), промокоды (владелец создаёт один код или пачку, отзывает и смотрит использование на `/admin/promo`), реферальная программа (`/r/код`, награда пригласившему за первую покупку приглашённого).
* Блог: 8 статей про поиск клиентов в `src/content/` (первое сообщение, напоминания, проверка сайта, SMM, вывески, закон о рекламе), разметка Article и BreadcrumbList, попадают в sitemap.
* Пакетные питчи: в «Моих лидах» одной кнопкой питчи для всех открытых лидов без текста, тексты сохраняются, отправка в WhatsApp, Telegram, почту или звонок в один клик, питчи попадают в CSV.
* Страницы городов и ниш для поиска (`/city/kazan`, `/city/kazan/medical`) и sitemap с ними.
* Открытие сразу всех лидов на странице каталога, одной транзакцией.
* Переключатель «Подписка / Разовые пакеты» на главной и в `/pricing`: тариф и срок выбираются кликом, кнопка «Купить подписку» ведёт на оплату. Кредиты по подписке приходят раз в месяц (начисляются при заходе пользователя).
* Права подписки сверх кредитов (`src/lib/plans.ts`, `src/lib/entitlements.ts`): эксклюзив на заведение (`src/lib/claims.ts`: другие не смогут открыть его 30 дней, за 3 кредита), отчёт о проверке сайта для клиента по ссылке (`src/lib/reports.ts`, страница `/report/<токен>`), скидка подписчикам на докупку пакетов, повышенные награда за приглашённых и лимит питчей. Всем показывается, сколько других пользователей уже открыли заведение.
* Вход и регистрация через Telegram Login Widget вторым способом (`src/lib/telegram.ts`, `/api/auth/telegram`): подпись проверяется по токену бота, новый аккаунт создаётся только после двух отметок (оферта и согласие). Включается переменными `TELEGRAM_BOT_USERNAME` и `TELEGRAM_BOT_TOKEN`. Если окно подтверждения Telegram не присылает сообщение, есть вход через бота («Войти через бота»: ссылка на бота, Start и «Да, это я»; `src/lib/tg-login.ts`, вебхук `/api/telegram/webhook`). Вебхук владелец подключает кнопкой в `/admin/telegram`, там же проверка токена и имени бота. Telegram можно привязать к аккаунту с почтой в «Аккаунте» (`src/lib/account-link.ts`): если этот Telegram уже заходил отдельно, аккаунты объединяются после подтверждения, весь перенос в одной транзакции и с записью в `account_merges`.
* Оферта `/terms`, политика `/privacy` и согласие `/consent` по 152-ФЗ: тексты в `src/lib/legal.ts`, реквизиты из `SELLER_*`. При регистрации две отдельные отметки (оферта и согласие), версия и время сохраняются.
* `/admin` для владельца: обзор с метриками, промокоды (один код или пачка, отзыв, CSV), пользователи (поиск, ручное начисление и списание кредитов). Видна только e-mail из `ADMIN_EMAILS`, остальным 404.
* Карточка лида, проверка сайта, питч, этапы и заметки; «Мои лиды» с фильтром по этапам и выгрузкой в CSV.

## Как устроено

```
ingest/overture.py   Overture Places по России -> data/overture_ru.parquet
ingest/osm.py        OSM через Overpass плитками с кэшем -> data/osm_ru.parquet
ingest/build_db.py   ниши, склейка дублей, города, скоринг -> data/leads.db (SQLite + FTS5)
ingest/niches.py     какие категории считаем нишами фрилансера
ingest/common.py     нормализация, классификация ссылок, скоринг, подсказки услуг
src/lib/db.ts        две libSQL-базы: каталог (только чтение) и аккаунты/кредиты/платежи
src/lib/search.ts    поиск по каталогу; единственное место, где контакты вырезаются, пока лид не открыт
src/lib/credits.ts   разблокировка за кредит одной транзакцией, баланс, история
src/lib/billing.ts   пакеты, платёж в ЮKassa, вебхук со сверкой статуса и суммы, тестовая оплата
src/lib/auth.ts      регистрация и вход (scrypt), сессии в cookie
src/lib/audit.ts     проверка сайта: HTTPS, адаптивность, телефон, заброшенность; защита от SSRF
src/lib/pitch.ts     питч через Claude (structured output) или шаблон
src/app/             лендинг (/), каталог с фильтрами (/leads), карточка лида, мои лиды со статусами, тарифы, оферта
src/lib/crm.ts       этапы работы с лидом (новый, написал, ответили, сделка, отказ) и заметки
src/components/      тема (светлая/тёмная), фильтры, оценка-кольцо, питч и проверка сайта
```

Оценка лида (0–100) считается в `ingest/common.py::lead_score`: сильнее всего влияет отсутствие своего сайта, затем телефон,
e-mail, соцсети и «чек» ниши; сетевые заведения получают штраф.
