# Чек-лист запуска

Что уже работает на https://findwork-rouge.vercel.app: каталог, фильтры, карточки лидов, регистрация по e-mail и через Telegram-бота, кредиты и подписки
(без автопродления), эксклюзив на заведение, отчёт для клиента по ссылке, этапы и заметки, страницы городов и ниш, блог, светлая и тёмная тема,
оферта, политика и согласие, админка (метрики, промокоды, пользователи, блокировка, кредиты, диагностика бота), самостоятельное удаление аккаунта.
Ниже то, что может сделать только владелец.

## Первым делом

- [ ] Проверить регистрацию через Telegram живьём: `/signup` → «Войти через Telegram» → «Открыть бота» → Start → «Да, это я». Если бот молчит, смотрите `/admin/telegram`.
- [x] Оплата подключена (магазин ЮKassa, ключи в Vercel), тестовый платёж прошёл. Вебхук в кабинете: `https://ваш-домен/api/billing/yookassa`. Подробности: [docs/PAYMENTS.md](PAYMENTS.md).
- [x] Юрист прочитал `/terms`, `/privacy`, `/consent`: замечаний нет. После любых правок текстов в `src/lib/legal.ts` поднимайте `LEGAL_VERSION`.

## Обязательно перед приёмом денег

- [x] Реквизиты продавца в Vercel: `SELLER_NAME`, `SELLER_INN`, `SUPPORT_EMAIL`, `SELLER_PHONE`, `SELLER_TELEGRAM` (взяты из проекта mystara, подставляются в оферту, политику и контакты). Если вы не самозанятый, задайте `SELLER_STATUS` (например, «индивидуальный предприниматель»), `SELLER_OGRN`, `SELLER_ADDRESS`: тогда в оферте будет чек по 54-ФЗ вместо «Мой налог».
- [x] **152-ФЗ, локализация**: с 23.10.2026 сайт и базы (аккаунты, платежи) на сервере Рег.облака в Москве, `PD_RU_HOST` задан, политика и согласие (редакция 1.10) говорят о хранении в РФ. За границу уходят только уведомления ЮKassa и сообщения бота, которые пересылает Vercel, и данные Telegram. Старая копия базы аккаунтов осталась в Turso (на момент переезда: один аккаунт владельца); её можно удалить.
- [ ] Уведомление Роскомнадзора о начале обработки (ст. 22) и о трансграничной передаче (ст. 12): подаёт оператор через сайт РКН до запуска.
- [ ] Чеки: самозанятый формирует чек в «Мой налог» по каждому платежу (ЮKassa чеки самозанятым не выдаёт). Возвраты делаются вручную в кабинете ЮKassa, затем кредиты списываются в админке («Забрать все кредиты» или «Начислить кредиты» с минусом).
- [ ] Для ИП и ООО с «Чеками от ЮKassa»: `YOOKASSA_RECEIPT=1`, проверить `YOOKASSA_VAT_CODE` и `YOOKASSA_PAYMENT_SUBJECT` с бухгалтером. Аккаунты только с Telegram при включённых чеках оплачивать не смогут: чеку нужен e-mail.
- [ ] Тестовый платёж на боевом сайте (в тестовом магазине ЮKassa) и проверка, что кредиты и подписка зачислились.
- [x] Vercel: после переезда на свой сервер (docs/SERVER.md) Pro не нужен. Vercel на Hobby только перенаправляет старый адрес и пересылает уведомления, проверка на бота посетителей больше не касается.

## Желательно

- [ ] Почта для сброса пароля: аккаунт Resend, подтверждённый домен, `RESEND_API_KEY` и `EMAIL_FROM`. Без них ссылка «Забыли пароль?» говорит, что сброс не подключён.
- [ ] `ANTHROPIC_API_KEY`: питчи от Claude вместо шаблона. Без ключа сайт честно пишет «готовый питч» и не упоминает Claude; с ключом тексты на лендинге и в тарифах сами меняются на «Питч от Claude». Модель задаётся в `ANTHROPIC_MODEL`.
- [x] Домен `lidomap.ru` подключён через прокси в Москве: российские провайдеры обрывают соединения с Vercel на ~16 КБ, и без прокси сайт у посетителей из РФ не работал (не грузились скрипты, не выбирался город). DNS у Vercel, `lidomap.ru` и `www` смотрят на сервер Рег.облака 89.111.175.104 (nginx и Let's Encrypt, настройка в `deploy/proxy/`, вход по ключу `~/.ssh/lidomap_proxy`), он пересылает запросы на Vercel. `APP_URL=https://lidomap.ru`, старый адрес `findwork-rouge.vercel.app` перенаправляет на новый, кроме вебхуков ЮKassa и Telegram. Настоящий IP посетителя прокси передаёт с секретом `PROXY_SECRET` (`scripts/proxy-secret.sh`).
- [x] После переезда на домен: адрес сайта в ЮKassa сменён на `https://lidomap.ru` (вебхук может остаться на старом адресе, он не перенаправляется), бот в @BotFather переименован, права на `lidomap.ru` подтверждены в Яндекс Вебмастере и Search Console (файлы подтверждения в `public/`). По желанию купить `лидомап.рф` для перенаправления.
- [ ] Живой платёж на `lidomap.ru`: купить самый дешёвый пакет и убедиться, что кредиты пришли.
- [x] Яндекс Вебмастер и Google Search Console: права подтверждены, `sitemap.xml` около 860 адресов. Яндексу страницы отправлены через IndexNow 22.10 (`node scripts/indexnow.mjs`, ключ в `public/`); запускайте его после выкладки новых статей или страниц, можно с конкретными адресами.
- [ ] Реферальная награда по умолчанию 10 кредитов (`REFERRAL_REWARD_CREDITS`, 0 выключает), приветственный бонус 3 кредита (`SIGNUP_BONUS_CREDITS`). Это бизнес-решения, проверьте размеры. Цены и права тарифов: `src/lib/plans.ts`.

## Что сделано и как устроено

- [x] Вход и регистрация через Telegram: только через бота (Start и «Да, это я»), вебхук сайт подключает сам, состояние в `/admin/telegram`. Telegram привязывается к аккаунту с почтой в «Аккаунте», отдельные аккаунты при этом объединяются после подтверждения.
- [x] `ADMIN_EMAILS` задан для sgovno616@gmail.com: в шапке «Админка». Кредиты владельца не входят в «продано» и «на балансах».
- [x] Блокировка пользователей закрывает вход и сессии, освобождает эксклюзивы, отзывает отчёты; оферта допускает аннулирование бонусных кредитов. Оплаченные кредиты при блокировке нужно вернуть деньгами.
- [x] Самостоятельное удаление аккаунта: стирает почту, пароль, Telegram, заметки, открытые заведения; платежи остаются обезличенными, хеш почты хранится до года против повторного бонуса. Пока идёт оплаченная подписка, удалить нельзя.
- [x] Страницы городов и ниш и sitemap читают сводку `city_niche` (ingest/city_niche.sql, уже залита в Turso). При пересборке каталога она создаётся автоматически.
- [x] Функции Vercel работают во Франкфурте (`vercel.json`), рядом с базами Turso.
