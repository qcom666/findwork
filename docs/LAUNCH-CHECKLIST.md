# Чек-лист запуска

Что уже работает на https://findwork-rouge.vercel.app: каталог, фильтры, карточки лидов, регистрация и вход, кредиты, этапы и заметки,
страницы городов и ниш, светлая и тёмная тема. Ниже то, что может сделать только владелец.

## Обязательно перед приёмом денег

- [x] Реквизиты продавца в Vercel: `SELLER_NAME`, `SELLER_INN`, `SUPPORT_EMAIL`, `SELLER_PHONE`, `SELLER_TELEGRAM` (взяты из проекта mystara, подставляются в оферту, политику и контакты). Если вы не самозанятый, задайте `SELLER_STATUS` (например, «индивидуальный предприниматель»), `SELLER_OGRN`, `SELLER_ADDRESS`: тогда в оферте будет чек по 54-ФЗ вместо «Мой налог».
- [ ] Юрист читает `/terms` (оферта), `/privacy` (политика), `/consent` (согласие): тексты составлены по 152-ФЗ и ГК, но это не юридическая консультация.
- [ ] **152-ФЗ, локализация**: база аккаунтов сейчас на Turso (AWS, Ирландия), хостинг Vercel (США). Для граждан РФ ч. 5 ст. 18 требует первичной записи и хранения в базе на территории РФ. План переезда на российский Postgres описан в `docs/LAUNCH_RF.md` проекта mystara. После переезда задайте `PD_RU_HOST` (например, «Selectel, Москва»): политика и согласие сами заменят абзац о хранении.
- [ ] Уведомление Роскомнадзора о начале обработки (ст. 22) и о трансграничной передаче (ст. 12): подаёт оператор через сайт РКН до запуска.
- [ ] Чеки: самозанятый формирует чек в «Мой налог» по каждому платежу (ЮKassa чеки самозанятым не выдаёт); возвраты делаются вручную в кабинете ЮKassa, затем кредиты можно списать в админке («Начислить кредиты» с отрицательной суммой).
- [ ] ЮKassa: магазин, `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`, вебхук `https://ваш-домен/api/billing/yookassa` (события `payment.succeeded`, `payment.canceled`).
- [ ] Для ИП и ООО с «Чеками от ЮKassa»: `YOOKASSA_RECEIPT=1`, проверить `YOOKASSA_VAT_CODE` и `YOOKASSA_PAYMENT_SUBJECT` с бухгалтером.
- [ ] Тестовый платёж на боевом сайте (в тестовом магазине ЮKassa) и проверка, что кредиты зачислились.
- [ ] Vercel: тариф Pro (Hobby только для некоммерческого использования).

## Желательно

- [ ] Почта для сброса пароля: аккаунт Resend, подтверждённый домен, `RESEND_API_KEY` и `EMAIL_FROM`. Без них ссылка «Забыли пароль?» говорит, что сброс не подключён.
- [ ] Вход через Telegram (код готов, ждёт бота): в @BotFather `/newbot`, затем `/setdomain` с доменом сайта; в Vercel задать `TELEGRAM_BOT_USERNAME` (имя без @) и `TELEGRAM_BOT_TOKEN` (секрет, вводит владелец) и передеплоить. Пока переменных нет, блок с Telegram на страницах входа скрыт. Смените домен: `/setdomain` заново. У таких аккаунтов нет почты: нет сброса пароля, а при `YOOKASSA_RECEIPT=1` оплата для них закрыта (чек уходит на e-mail).
- [ ] Реферальная награда по умолчанию 10 кредитов (`REFERRAL_REWARD_CREDITS`, 0 выключает). Это бизнес-решение, проверьте размер.
- [ ] `ANTHROPIC_API_KEY`: питчи от Claude вместо шаблона. Модель задаётся в `ANTHROPIC_MODEL`.
- [x] `ADMIN_EMAILS` задан для sgovno616@gmail.com: после входа в шапке появляется «Админка» (обзор, промокоды, пользователи).
- [ ] Свой домен (Vercel → Settings → Domains), затем обновить `APP_URL` и адрес вебхука в ЮKassa.
- [ ] Яндекс Вебмастер и Google Search Console: добавить сайт и `sitemap.xml` (около 840 адресов).

## Что пока не сделано

- Подписки без автопродления (оплата один раз на срок, кредиты приходят раз в месяц). Автопродление с привязкой карты требует рекуррентных платежей ЮKassa и отдельного согласия: сейчас не включено.
- Самостоятельное удаление аккаунта: пока по письму на почту поддержки (политика обещает до 30 дней).
- Подтверждение e-mail при регистрации: нужна та же почта.
- Данные OSM: код загрузки есть (`ingest/osm.py`), но публичный Overpass слишком медленный для полного прогона. Для всей России берите выгрузку Geofabrik.
- Реестр МСП ФНС как сигнал «новая компания».
- Живая проверка питча от Claude и боевой платёж ЮKassa: нужны ваши ключи.
